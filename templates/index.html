How to use

  1. Install the Get cookies.txt LOCALLY browser extension
  2. Log into Canvas in your browser
  3. On the Canvas site, click the extension icon and export cookies
  4. Paste the Canvas page URL below
  5. Upload the cookies.txt file and click Download
